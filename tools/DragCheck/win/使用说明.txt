UnityProjectInspector 一键检查（Windows 版）
===========================================

这是什么
--------
自动检查一个 Unity 工程是否完整：工程结构、场景文件、对象层级等，
并生成一份中文 HTML「体检报告」（结论横幅 + 统计 + 检查明细 +
Unity 风格场景层级树 + 修复建议）。

怎么用（超简单）
----------------
1. 把整个文件夹解压出来（例如放到桌面）；
2. 把学生的 Unity 工程【zip 压缩包】或【工程文件夹】直接拖到
   check_unity_project.bat 上，松开鼠标；
3. 自动完成：解压 → 校验 → 自动生成检查方案 → 检查 → 打开报告。

什么都不用装：不需要安装 .NET、不需要安装 Python、不需要 Unity。

注意事项
--------
- 首次使用如果 Windows 提示「已保护你的电脑 / SmartScreen」，
  点「更多信息」→「仍要运行」即可（这是常见提示，程序本身安全）。
- 工程 zip 必须是 Unity 工程本身的压缩包（内含 Assets /
  ProjectSettings / Packages 目录）。
- 大工程检查需要几秒到几十秒，请耐心等待。

命令行用法（可选）
------------------
check_unity_project.bat "D:\某个工程.zip"
